# Changelog

## Unreleased
- **Fix:** opening Ultimyr in two tabs at once, or any two refreshes that overlap, no longer signs you out. A refresh that arrives within 10 seconds of the rotation that replaced its cookie now gets an access token instead of being treated as theft. Replays after that window still revoke the whole session. Adds migration `0006_refresh_grace`; redeploy with `docker compose up -d --build`.
- **New: admins can create accounts by hand, and local accounts can be turned off.** Admin panel > Users > **Add a person** creates a user with a name, email and roles, then either a one-time **invite link** (valid 7 days, they choose their own password) or a **temporary password** (generated or typed) that must be replaced at first sign-in. **New sign-in link** on a user's row reissues a link. A new **Disable local accounts** switch in Sign-in methods (off by default) makes the server refuse password, passkey, sign-up and session access for accounts not from SSO or SCIM. It needs an enabled provider, and local administrators stay exempt as a break-glass sign-in. API: `POST /admin/users`, `POST /admin/users/:id/invite`, `POST /auth/set-password`, `POST /auth/change-password`, `localUsersDisabled` in `/admin/settings`. Adds migration `0005_manual_users` (auth). See docs/identity.md.
- **Fix: the notes container failed to start, which blocked the web app and MCP.** The service bundles could not load a bundled dependency (`Dynamic require of "net" is not supported`); this is fixed for the content, quiz, AI gateway and notes bundles. The web app and MCP no longer wait on the notes service, a bad vault key now switches notes off with a log line instead of crashing, and CI now starts every built bundle and checks `/healthz`.
- **New: flashcards from notes, and Claude can work with your step notes.** **Make a deck** in the note pane turns the `Question :: Answer` lines under `## Flashcards` into a deck. New MCP tools `get_step_note`, `append_step_note` (adds to the end, never edits what you wrote) and `get_step_flashcards`, under a new `notes:use` scope that is part of the default MCP consent (untick it to keep notes private). The MCP service now needs `NOTES_URL` (compose sets it). API: `POST /notes/steps/:id/append` and `GET /notes/steps/:id/flashcards`.
- **New: notes in Obsidian, beside your roadmap.** Connect your own Fast Note Sync vault (Settings > Notes), press **Create notes** on a roadmap and every step gets a Markdown note in the standard layout (`docs/notes.md`). The note icon on a step opens it side by side with the roadmap to edit and preview; **Open in Obsidian** jumps to the same note. Ticking a step updates the note's `status` property. Scaffolding never overwrites, saves are refused if the note changed in Obsidian meanwhile, and the sync token is stored encrypted and never shown. New `notes` service (schema `notes`, migration `0001_notes`, port 4006, scope `notes:use`), optional `docker-compose.notes.yml` to run a Fast Note Sync server, and `FNS_URL` to point at yours. Leave `FNS_URL` empty and notes stay off. Behind Traefik, `/api/v1/notes` goes to the new service. Redeploy with `docker compose up -d --build`.
- **New: nested roadmaps and outline import.** A step can hold steps (a course holds lessons, a lesson holds pages or videos), three levels deep. Only the innermost steps carry a tick; a parent shows its own progress, shows a partly done state, and ticking it ticks everything inside. **Paste an outline** (Roadmap tab, the API, or the new MCP tool `import_outline`) to load a whole certification in one go: `## Stage`, nested bullets, `[Title](https://link) 20m`, `[[Guide title]]`, `(optional)`. Archive export and import carry nested steps. Limits are now 1,000 steps and 1,500 resources per archive. Adds migration `0004_nested_steps`.
- **New: roadmaps and external resources.** Link training material from outside Ultimyr (YouTube videos and playlists, Anthropic's training pages, docs, courses, books, podcasts) and lay it out as a roadmap: ordered stages of steps that mix your own guides, decks and quizzes with links and checkpoints. Mark steps required or optional, add notes and time estimates, and tick steps off. Each archive gets **Material, Roadmap and Resources** tabs (themed names: Path and References), the dashboard shows a **Keep going** card per roadmap with progress, minutes left and the next step, and search finds saved links. Links must be `https`, open in a new tab and are never fetched by the server. Adds migration `0003_roadmap` (content service).
- **API and MCP:** new routes for resources, roadmaps and progress (see api.md), archive export and import now carry resources and the roadmap, and MCP gains `list_resources`, `get_roadmap`, `add_resources`, `set_roadmap` and a `build_roadmap` prompt. MCP writes are drafts a person publishes. Behind Traefik, the content router also forwards `/api/v1/resources` and `/api/v1/roadmap`.
- **New:** guided SCIM setup in Admin panel > Provisioning. Choose authentik (default), Okta, Microsoft Entra ID, Keycloak or any other provider, then follow numbered steps with copy buttons for the address and token, inline token generation, a progress checklist and links straight to the matching page in your provider. Includes a terminal connection check.
- **Settings rework:** your own settings now live behind the account icon in the menu bar (Your settings: display, security, AI keys, connected apps, themed names, which stays at the bottom and is off by default). Administrators also get an **Admin panel** there, with a category list on the left that opens on General, then Users, Groups, Sign-in methods, Provisioning and the Audit log. Non-admins never see it, and the server rejects admin calls from anyone without the administrator role.
- **New:** admins can open or close registration from General (`GET/PATCH /api/v1/admin/settings`, `GET /api/v1/admin/overview`). It overrides `AUTH_REGISTRATION` until reset. Adds migration `0004_instance_settings`.
- **Fix:** clicking the Ultimyr logo no longer looks like a sign out. The splash page ignored your session and its button led to the sign in form. Signed in people now go straight to the reading room from the logo and the splash, and the sign in and register pages send them on instead of showing the form.

## 1.0.0 (2026-10-04)
First complete release. All nine roadmap phases are in.

- **Platform:** pnpm TypeScript monorepo, Fastify services (auth, content, quiz, AI gateway, MCP), Next.js web app, Postgres with one schema per service, Docker Compose with Nginx Proxy Manager (default) or Traefik.
- **Identity:** passwords, TOTP, passkeys, API keys, OIDC, OAuth2, SAML, SCIM 2.0, groups, admin API.
- **Content:** archives, guides, decks, versions, sharing, search, import and export, trash.
- **Quizzes:** five question types, practice, timed and exam modes with a server clock, exact versioned scoring.
- **Study:** FSRS-5 daily review, progress, goals, readiness estimate.
- **AI:** bring your own Gemini, OpenAI or Anthropic key, encrypted per person, draft generation, study assistant.
- **MCP:** OAuth 2.1 connected apps, scoped tools, drafts for writes.
- **Polish:** themes, text size, easy-read font, calm and focus modes, declared extra time, installable app with offline page, example archive, performance budget.
- **Hardening:** baseline security headers, `no-store` API responses, backup and restore scripts, load check script, security review and runbooks.

Not included: Gemini sign in with Google OAuth (paste a key instead), offline study, third-party audit.

Upgrading from an earlier phase build: back up first (`scripts/backup.sh`), then `git pull`, `./scripts/init-secrets.sh`, `docker compose up -d --build`. Migrations run automatically and are forward only.
