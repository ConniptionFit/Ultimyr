# Changelog

## Unreleased
- **New: mobile friendly layout.** On a phone the top bar shows a search button and a menu button that opens a full-screen menu with every page, your settings, the Admin panel (if you can open it) and Sign out. Settings and Admin categories scroll sideways as a row of tabs, archive tabs scroll instead of overflowing, wide Markdown tables scroll inside their own box, page padding is tighter, inputs use 16px text so iOS does not zoom on focus, buttons and inputs are at least 40px tall on touch screens, and the exam question number buttons are larger. On screens narrower than 1024px a saved split-screen notes choice opens the note full screen instead (your saved choice is kept for larger screens). Layout only, no migrations; `git pull && docker compose up -d --build` is enough.
- **New: watch videos inside Ultimyr.** A saved link that is a video (kind video or playlist, or tagged `content-type:video`) now shows a play button instead of its icon, on the Resources tab and on roadmap steps. Press it to drop a player down under the row, press again to fold it away. YouTube (privacy-enhanced domain, start time and playlists kept), Vimeo (do not track, unlisted hashes) and Loom links play in an embed; direct `.mp4`, `.webm`, `.ogv` and `.mov` links use the browser's own player. Nothing loads from another site until you press play. Other sites, and anything that is not a video, stay ordinary links, and every player offers **Open the original** in case a video blocks embedding. No migrations or API changes. If your reverse proxy sets a Content-Security-Policy, allow the player hosts listed in docs/content.md.
- **New: guided Obsidian (Fast Note Sync) setup, a notes folder you choose, and your choice of editor and pane.** Admins set the server address in **Admin panel > Notes (Obsidian)** (checked before saving; `FNS_URL` is now optional). Settings > Notes is a short guided connect: paste your token, check it, pick your vault, pick a folder (default `Ultimyr`, existing folders suggested). On a roadmap, **Set up notes** previews the exact file tree, which mirrors the roadmap's stages and nested steps, before it creates anything. You choose where you edit (**In Ultimyr** or **In Obsidian**) and the notes pane: **split screen with a draggable slider**, **full screen** with charms back to the roadmap, the main menu and the previous or next step, or **off**. Settings now say exactly why notes are unavailable (no vault key or no server). The notes service migrates itself at start and reports missing tables as "notes are not ready" instead of "internal error". Adds migration `0002_settings_preferences` (notes). See docs/notes.md and ADR 0016.
- **New: exam prep tools.** (1) **Credential tracker** (Exam prep > Credentials): exam dates, voucher codes and expiry, renewal dates and CEU hours with a log, plus alerts in the Reading Room. (2) **Weak-area drills** (Exam prep > Drills): a short quiz built from your weakest or most missed questions, never more than 60% from one area. (3) **Coverage map** (new Coverage tab on an archive): import the exam objectives, link material and questions to them, and see gaps. (4) **Exam-day countdown** (Exam prep > Exam day): a day by day plan, adjusted to your minutes per day and exam mode, plus a checklist. Drills do not change the readiness estimate. New MCP tools `get_objectives`, `set_objectives`, `link_objectives`, `link_questions`, `get_coverage`, `get_credentials`, `get_exam_plan`. Adds migrations `0005_credentials` and `0006_objectives` (content), `0004_drills_objectives` (quiz) and the shared package `@ultimyr/coverage`. Behind Traefik, the content router also forwards `/api/v1/credentials` and the quiz router `/api/v1/drills` and `/api/v1/plan`. The JavaScript budget rose from 450 KB to 500 KB for this. Each tool has a themed name (Sigils, Whetstone, Atlas, The Eve, under Preparations) you can switch off in Your settings. See docs/prep.md.
- **Fix: "This page couldn't load" after the tab icon update.** The tab icon component sat outside the sign-in provider in the root layout, so every page failed to render. It now lives inside it. No migrations; `git pull && docker compose up -d --build` is enough.
- **New: tags and a full icon library.** Courses, sections (roadmap stages and steps), saved links, guides, decks, quizzes and exam objectives can be tagged with `namespace:value` tags: what they cover (`topic:ai`, `topic:networking`) and what kind of material they are (`content-type:video`, `content-type:reading`, `content-type:lab`). A video link is a video automatically, and adding `reading` to it covers a video with a written summary. Tags are also read from titles and linked exam objectives (never stored). All 1,866 Lucide icons are now bundled (pinned version, ISC license, nothing fetched from the internet), each with what it depicts and the tags it suits. Icons are ranked by how many of a section's tags they match, and the best one is assigned automatically where it is a confident match and you have not chosen one. An icon you pick yourself is never replaced; **Choose for me** in the archive icon picker hands it back. The picker also searches every icon. Roadmap stages show their icon and tags. API: `/tags/vocabulary`, `/icons`, `/icons/suggest`, `/archives/:id/tags`, `/archives/:id/icons`, `/archives/:id/icon-suggestions`. MCP: `get_tag_vocabulary`, `get_tags`, `set_tags`, `search_icons`, `suggest_icons`, `set_icons`. Adds migration `0008_tagging` (content), applied by `docker compose up -d --build`; courses that already had a custom icon keep it as your choice. Behind Traefik, the content router also forwards `/api/v1/tags` and `/api/v1/icons`; behind Nginx Proxy Manager route those paths to the content service too. New package `@ultimyr/tagging`. See docs/tagging.md.
- **New: a tab icon.** The browser tab now shows a graduation cap. Before sign in it uses the dark mode accent green; once signed in it takes the accent colour of your active theme and updates when you switch light, dark or system. No migrations.
- **New: Group access in the Admin panel (themed: Keys of Passage), and an Access delegate role.** Pick a group (SCIM groups included), then set each course to No access, Can view or Can manage, and see which courses are Open to everyone or Restricted. Existing content keeps its visibility, so upgrading locks nobody out until an administrator clicks Restrict. The new **Access delegate** role lets a non-admin manage group access only for the courses an administrator delegated to them (Group access > Delegates); delegates see only that page and cannot change who a course is open to, delegate onwards or touch other settings. API: `/group-access/...` (see api.md). Adds migrations `0006_access_delegate_role` (auth) and `0007_group_access` (content), applied by `docker compose up -d --build`. Behind Traefik, the content router also forwards `/api/v1/group-access`; behind Nginx Proxy Manager route that path to the content service too.
- **New: About this app in the Admin panel** (themed: Colophon). Shows the name, repository link, license, the version and commit this install is running, whether a newer release or newer changes on `main` exist, the changelog for the latest version, and links to docs, releases, issue reporting and private security reporting. The build records its version and git commit when the image is built, so `git pull && docker compose up -d --build` is enough. The update check asks GitHub from the auth service, is cached for an hour, fails quietly offline, and can be switched off with `ULTIMYR_UPDATE_CHECK=false` (`ULTIMYR_REPO` points it at a fork). API: `GET /admin/about`. No migrations.
- **New: build a certification with any chat, no connector or API key.** On Exam prep > Build with an AI assistant, copy the prompt into Gemini, ChatGPT or Claude. It writes objectives, a roadmap, guides, flashcards and questions as text in a strict format, in chunks if long. Paste or upload the text, Ultimyr checks it line by line (cut-off blocks and unreadable lines are reported with line numbers), and saves it as drafts into a new or existing archive. Re-running never duplicates guides, decks, cards or questions. New package `@ultimyr/bundle`; no migrations or API changes. See docs/bundle.md.
- **New: build a whole certification from one chat prompt.** Exam prep > Build with an AI assistant (themed: Commission the Archivist) gives you a ready prompt for Claude or any MCP assistant: it asks for the official exam objectives, then saves objectives, a roadmap, study guides, flashcards and questions in small batches, all as drafts. Each archive's Coverage tab shows build progress and a prompt to continue in a new chat. New MCP tool `get_build_queue`, new prompts `build_certification` and `continue_build`, and `create_guide` and `create_deck` accept `objectiveIds` to link material as it is created. No migrations. See docs/mcp.md.

## 1.0.0 (2026-10-04)
First complete release. All nine roadmap phases are in.

- **Platform:** pnpm TypeScript monorepo, Fastify services (auth, content, quiz, AI gateway, MCP), Next.js web app, Postgres with one schema per service, Docker Compose with Nginx Proxy Manager (default) or Traefik.
- **Identity:** passwords, TOTP, passkeys, API keys, OIDC, OAuth2, SAML, SCIM 2.0, groups, admin API.
- **Content:** archives, guides, decks, versions, sharing, search, import and export, trash.
- **Quizzes:** five question types, practice, timed and exam modes with a server clock, exact versioned scoring.
- **Study:** FSRS-5 daily review, progress, goals, readiness estimate.
- **AI:** bring your own Gemini, OpenAI or Anthropic key, encrypted per person, draft generation, study assistant.
- **MCP:** OAuth 2.1 connected apps, scoped tools, drafts for writes.
- **Polish:** themes, text size, easy-read font, calm and focus modes, declared extra time, installable app with offline page, example archive, performance budget.
- **Hardening:** baseline security headers, `no-store` API responses, backup and restore scripts, load check script, security review and runbooks.

Not included: Gemini sign in with Google OAuth (paste a key instead), offline study, third-party audit.

Upgrading from an earlier phase build: back up first (`scripts/backup.sh`), then `git pull`, `./scripts/init-secrets.sh`, `docker compose up -d --build`. Migrations run automatically and are forward only.
